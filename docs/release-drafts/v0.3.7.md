# PriorityGear v0.3.7

PriorityGear v0.3.7 is a packaging reliability follow-up to v0.3.6.

## What's Changed

- The GitHub installer ZIP is now self-contained.
- `PriorityGear.Setup.exe`, the GUI app, CLI, and System Mode service can run on a clean Windows machine without a separately installed .NET Desktop Runtime.
- Windows Sandbox validation passed with no `dotnet` command found and no `Microsoft.WindowsDesktop.App` registry key found.
- Silent install succeeded with no .NET runtime prompt.
- `PriorityGear.Service` was created and running as LocalSystem.
- CLI `service status` succeeded.
- CLI `core-topology` succeeded.
- Silent uninstall succeeded.
- `%ProgramData%\PriorityGear` is preserved by design.

## Known Limitations

- GPU process attribution remains unsupported unless a verified PID-attributed source is added later.
- Multiple processor groups are rejected by the current Core Reserve affinity path.
- Protected or elevated processes may require System Mode.
- Deleting a rule does not necessarily restore priority or affinity already applied to a running process.
- winget update is not included in this release and will be handled after release publication.
